目前是現場模式:可看田區位置、地號、面積、噸數、現場照片、備註與導航。業主與農會承辦的個人資料已加密保護。

① 手機與電腦即時同步(同步碼)

資料與照片存在你自己的 Cloudflare 帳號。設定一組同步碼(至少 6 個字),換手機只要輸入同一組,專案與照片就會自動回來。

② 給現場施工人員的檔案

產生一個含照片的檔案。業主姓名電話、農會承辦電話、備註與申報文件清單會用密碼加密;現場人員看得到田區、照片、業務聯絡方式與農會名稱。

③ 備份與還原

④ Google 雲端硬碟備份

把專案、照片、申報文件備份到你自己的雲端硬碟。設定方式見 README 與 GAS 程式檔。

⑤ Google 地圖搜尋

填入 Google Maps Platform 的 API 金鑰,搜尋就會和 Google 地圖一樣找得到農會、店家、門牌。沒填則用免費的 OpenStreetMap 資料。

設定後,鎖定或匯出現場版都用這組密碼;現場人員要看客戶資料也需要它。密碼只以雜湊值存在本機,忘記無法救回。
