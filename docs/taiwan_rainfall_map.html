📌 為什麼有機肥對雨量比化肥敏感？
1. 顆粒比較大，雨水浸泡 1-2 天會泡爛、養分隨水流失到溝渠
2. 含微生物，連續陰雨 = 田面厭氧，菌相被破壞、肥效歸零
3. 多為粒狀/粉狀，需要機具撒佈，農路積水就根本無法出貨
4. 果樹/茶葉主要客戶在山區，雨季時連道路都不一定能通
